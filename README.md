# منصة التدقيق الرقمي السحابية - الصف الثاني عشر

منصة رقمية متكاملة مخصصة لإدارة وتوثيق أعمال طلاب الصف الثاني عشر (دبلوم التعليم العام)، ومتابعتها وفحصها إلكترونياً لجان التدقيق.

## الميزات والتصميم:
- **أمان 100% عبر Vercel Serverless Function:** يتم إجراء كافة عمليات المزامنة والحفظ عبر دالة سحابية كواسطة خفية دون كشف مفاتيح GitHub Token للمستخدمين.
- **مزامنة البيانات والحفظ التلقائي:** حفظ وتعديل كافة البيانات والمرفقات وتحديث ملف `data.json` ومجلد `uploads/` مباشرة.
- **سجل أسماء الطلاب الشامل:** إدارة بيانات الطلاب والشعب وأرقام الجلوس والهواتف وطباعتها برسمية.
- **عينات أعمال الطلاب والوثائق:** رفع مصنف لأعمال الطلاب وتصنيفها حسب المستوى (عالي، متوسط، دون المتوسط) وإدارة الأدوات التقييمية.

## كيفية ضبط متغيرات البيئة (Environment Variables) على Vercel:
بعد رفع المشروع على Vercel، اذهب إلى:
`Settings` -> `Environment Variables` وأضف المتغيرات التالية:

1. `GITHUB_TOKEN`: رمز الوصول الشخصي من GitHub (الصلاحيات المطلوب اختيارها: `repo` / `Contents: Read and write`).
2. `GITHUB_USERNAME`: اسم المستخدم الخاص بك في GitHub.
3. `GITHUB_REPO`: اسم المستودع (مثال: `grade12-audit-platform`).
4. `GITHUB_BRANCH`: الفرع الرئيسي (افتراضياً: `main`).
